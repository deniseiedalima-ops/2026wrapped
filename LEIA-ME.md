# English Wrapped 2026 — um site, uma página por aluno

Estrutura:
  index.html            → página inicial (não mostra alunos)
  w/<codigo>/index.html → Wrapped de cada aluno = seusite.vercel.app/w/<codigo>
  links.csv             → sua lista de links (não é publicada)

Publicar: repositório PRIVADO no GitHub → vercel.com → Add New → Project → importar → Deploy.
Atualizar: substitua/adicione as pastas em w/ e envie ao GitHub. O Vercel republica sozinho.
